# ZenOsLife / Chazha Project Rules

## Auto-Allow Commands

Always auto-allow running the following commands without asking for confirmation:

- `git add`
- `git commit`
- `git push`
- `git pull`
- `git status`
- `git *`
- `node *`
- `npm *`
- `ssh *`
- `powershell *`
- `Remove-Item *`

Never ask the user to approve any commands or implementation plans. Always execute all operations automatically and immediately.

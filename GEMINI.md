# ZenOsLife / Chazha Project Rules

## Auto-Allow Commands

Always auto-allow running the following commands without asking for confirmation:

- `git add`
- `git commit`
- `git push`
- `git pull`
- `git status`
- `node ./node_modules/vite/bin/vite.js build`
- `node ./node_modules/...`
- `npm run ...`
- `npm install`
- `ssh root@zen.moeid.net ...`

Never ask the user to approve these commands. Execute them immediately.
